## 🚀 About Me

Soy estudiante de 2do ciclo de Ingeniería de Software en la UPC, enfocado en construir **productos completos con TypeScript de punta a punta**: APIs robustas, escalables y seguras con **NestJS**, e interfaces modernas con **Next.js**.

Me estoy especializando en el desarrollo backend con **TypeScript, Node.js y NestJS**, bases de datos **PostgreSQL** y la integración de **LLMs** (RAG, agentes, streaming) en aplicaciones reales. Mi objetivo es diseñar, programar, probar y desplegar aplicaciones Full Stack de manera independiente, compartiendo tipos y contratos entre backend y frontend.
