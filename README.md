# 👋 Hola, soy Martin Caycho
### 🔧 Aspiring Backend Developer | TypeScript + NestJS + PostgreSQL

---

## 🚀 Sobre mí

Soy estudiante de 2do ciclo de Ingeniería de Software en la UPC y estoy construyendo mi camino como **Backend Developer**. Me enfoco en diseñar **APIs robustas, seguras y escalables** con **TypeScript, Node.js y NestJS**, respaldadas por bases de datos **PostgreSQL** bien modeladas.

Me interesa entender cómo se construye un backend de calidad: arquitectura modular, buenas prácticas, seguridad, testing y despliegue. También exploro la **integración de LLMs** (RAG, streaming, agentes) como una capa más dentro de servicios backend reales.

---

## 💼 Enfoque actual

- ⚙️ **Backend**: TypeScript, Node.js, NestJS, REST APIs, arquitectura modular
- 🗄️ **Base de datos**: PostgreSQL, SQL, modelado de datos, Prisma, migraciones
- 🔐 **Seguridad**: autenticación y autorización (Guards), JWT, hashing de contraseñas, validación de inputs
- 🏗️ **Arquitectura**: Clean Code, Inyección de Dependencias, Design Patterns, principios SOLID
- 🧪 **Testing**: Jest, pruebas unitarias, de integración y E2E con Supertest
- 🚀 **DevOps básico**: Docker, manejo de variables de entorno, CI/CD
- 🤖 **AI en el backend**: LLM APIs, streaming, embeddings, RAG, pgvector

## 📚 Aprendiendo actualmente

- **TypeScript**: tipos, interfaces, generics, utility types, type narrowing, configuración de `tsconfig`
- **Node.js**: módulos, HTTP, request / response, manejo de errores, variables de entorno
- **NestJS**: Modules, Controllers, Providers, Dependency Injection, Pipes, Guards, Interceptors, Exception Filters
- **HTTP & REST**: métodos, status codes, headers, principios de diseño de APIs, documentación con Swagger
- **PostgreSQL & SQL**: queries, joins, relaciones, normalización, índices, transacciones
- **ORM & Migraciones**: Prisma, schemas, migraciones, connection pooling
- **Seguridad**: password hashing, autenticación JWT, autorización, validación de inputs (`class-validator`), CORS, rate limiting
- **Testing**: Jest, unit tests, E2E tests
- **Deployment & DevOps**: Docker, variables de entorno, bases de CI/CD
- **LLMs en el backend**: prompting, streaming, embeddings, RAG, agentes
- **Next.js** (básico): App Router, Server/Client Components, consumo de APIs
